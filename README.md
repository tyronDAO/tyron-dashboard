# Tyron Dashboard

This `Dashboard` was bootstrapped from a SaaS application template from Tremor. It's built
using Tremor Raw
and Next.js.

## Getting started

1. Install the dependencies. We recommend using npm.

```bash
npm install
```

2. Then, start the development server:

```bash
npm run dev
```

3. Visit [http://localhost:3000](http://localhost:3000) in your browser to view
   the app.
